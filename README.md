# 🎨 Color Palette Generator

A simple and responsive Color Palette Generator built using **HTML**, **Sass (SCSS)**, and **TypeScript**. Instantly generate random color palettes and copy hex codes with a single click.

---

## ✨ Features

- 🎲 Generate random color palettes
- 📋 Click a color to copy the hex code to clipboard
- 📱 Fully responsive layout
- 🎨 Clean, modern design using Sass
- 🔐 Type-safe logic with TypeScript
